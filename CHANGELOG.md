# Changelog

This file records user-facing changes. Dates use the release date in the America/New_York time zone.

## 1.3.1, 2026-06-05

- The server now starts without credentials and keeps the complete tool catalog available for discovery. API calls return setup guidance until authentication is configured.
- The package and server metadata now report the same version.

## 1.3.0, 2026-06-02

- Added browser-based OAuth login with PKCE. This path needs a client ID but does not store a client secret.
- Added seven workflow tools for reports, comparisons, pagination, trend analysis, campaign drafts, scheduling, and case triage.

## 1.2.0, 2026-06-01

- Added interactive user login and local session refresh.
- Added the MCPB manifest and bundle metadata.
